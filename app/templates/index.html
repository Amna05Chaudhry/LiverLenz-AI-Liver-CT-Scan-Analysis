      About / How it works

      1

      Preprocess

      A CT slice in Hounsfield units becomes 3 channels: liver window (W150/L30), soft-tissue window (W200/L60) and a histogram-equalised channel, then is resized to 128×128.

      2

      Segment

      A SegNet-style encoder–decoder CNN (4.1 M parameters, trained on the public LiTS dataset) predicts a per-pixel liver probability; pixels above 0.5 form the mask.

      3

      Measure

      The mask is upsampled to the original size; area, bounding box, centroid, location and connected regions are computed with OpenCV.

      4

      Report & chat

      Findings come straight from the measurements. An LLM (Groq / Llama by default) writes the impression and answers questions; without an API key a template is used.

      The model segments the liver only; it does not detect tumours. Accuracy on an external held-out dataset is reported in the project README. By Amna Choudhri. Originally developed as a team university project; this version was refactored and extended by Amna Choudhri.
